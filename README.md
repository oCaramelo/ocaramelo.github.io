# oCaramelo.github.io

Personal page for Luís Marques - Python Developer, AI & Chatbot Engineer.

Static site: plain HTML/CSS/JS, no build step. Served by GitHub Pages from `main`.

- `index.html` - page content
- `css/style.css` - design system (light/dark tokens, layout)
- `js/script.js` - theme toggle, hero canvas animation, easter egg
- `assets/` - profile photo

Scaffolded via [`xorgentic new`](https://github.com/oCaramelo/xorgentic); the Python
project skeleton it generates by default was removed since this is a static page.
